# Badge

Le badge affiche un statut en un ou deux mots ; il ne se clique pas.

Correspondance des statuts du dilemme : En matching → `info` · Planifié / En cours d'échange → `foret` · Round publié → `cuivre` · Tenu, Livrable publié, Paiement confirmé → `success` · Expire bientôt, Délai dépassé → `warning` · Annulé, Paiement refusé → `danger` · Clos, Soumis → `neutral`.

Le mot porte toujours le sens : ne jamais compter sur la seule couleur.
